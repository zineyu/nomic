# ADR-0020: 专门的命令输入框（COMMAND 模式）

## Status

Accepted（2026-08-13）

修订 [ADR-0011](0011-vim-like-interaction.md)：COMMAND 从「INSERT + 预填 `/`」
升格为一等模式，slash 命令从聊天输入框（INSERT）迁出。

## Date

2026-08-13

## Context

ADR-0011 把 COMMAND 实现为「NORMAL `:` → 回 INSERT + 预填 `/`」的零成本
方案，命令与 prompt 共用草稿缓冲。随交互演进，这一共享带来三处持续的
别扭：

- **草稿与命令互相干扰**：`:` 在草稿非空时不能预填（只能提示「先处理
  草稿」）；命令输入途中的补全弹层、执行失败保留的输入都占用草稿缓冲，
  用户未发送的文本与命令在同一缓冲里此消彼长。
- **输入框一身二职，触发靠内容嗅探**：Enter 时按「是否以 `/` 开头」分
  流命令与 prompt，想给模型发一条以 `/` 开头的文本（如讨论某个命令）
  没有干净的路径；运行中的 Enter 更要区分本地命令/会话命令/普通输入三
  类，规则层次与 ADR-0011 批判的「按键语义依赖隐式上下文」同源。
- **模板调用与命令的边界模糊**：prompt template 经「未知命令」兜底展
  开，与内建命令共用同一触发面，用户难以预判 `/foo` 会执行什么。

vim 自身早已给出答案：命令行（`:`）是独立的缓冲与模式，与普通文本编辑
完全分离。把这一分离搬过来，命令触发面收敛到专门入口，输入框回归单一
职责。

## Decision

### 模式架构

新增一等模式 **COMMAND**（模式家族第七个），NORMAL 下 `:` 进入：

- **独立的命令缓冲**：`App` 持有两份输入缓冲——聊天草稿（INSERT/QUEUE
  就地编辑）与命令行（COMMAND）。进入 COMMAND 时命令缓冲清空并预填
  `/`（补全弹层随之列出全部命令）；离开即清空。草稿全程不受影响，
  ADR-0011 修订中「草稿非空时 `:` 不预填」的变通随之废止。
- **命令只在 COMMAND 执行**：slash 命令与 prompt template 调用的唯一触
  发面是命令行。聊天输入框不再触发命令——`/` 开头的草稿按普通
  prompt 发送（运行中照常排队入统一消息队列），slash 补全在草稿缓冲
  不再启用（skill/template 快照只挂到命令缓冲）。

### COMMAND 键位

| 键位 | 行为 |
|---|---|
| 可打印字符 / 编辑键 | 与 INSERT 相同（词级移动、删词、清行等） |
| `Tab` / `↑/↓` | 补全命令 / 模板 / skill，弹层内移动选中 |
| `Enter` | 补全未精确匹配时先填入候选；否则执行命令或展开模板 |
| `Esc` | 退回栈：关补全弹层 → 放弃回 NORMAL（缓冲清空） |
| `Ctrl+C` / `Ctrl+D` | 取消运行 / 退出（全局口径不变） |

Enter 的落地规则（与 vim `:` 同口径）：空命令行（仅预填的 `/`）无声返
回 NORMAL；命令被受理（含 `/help` 等就地命令、picker 类命令）后回
NORMAL；被拒绝（参数非法、未知命令、运行中的会话命令）时留在
COMMAND、输入保留，供修正后再次提交或 Esc 放弃。

运行中的口径不变，只是触发面换了位置：本地命令（`/help`、`/copy` 等）
照常执行不被工具调用阻塞；模板展开的 prompt 排入统一消息队列
（ADR-0014）；会话命令仍须等本轮结束。

### 视觉反馈

沿用 ADR-0011 的情境信号：状态栏 ` COMMAND ` 徽标与右侧键位提示、输入
框标题（运行中叠加 spinner）、光标保持竖条（键入态）；命令行打开期间
聊天区消息游标高亮保持（COMMAND 语境上属于浏览的延伸）。

## Non-goals

- 命令历史（vim 的 `q:` / `<Up>` 回忆）：命令行离开即清空，需求出现再议。
- 无 `/` 前缀的命令语法（`:help` 形式）：命令注册表、解析与补全统一以
  `/` 前缀为口径，预填保留。
- 聊天输入框内任何形式的命令触发（如 `Ctrl+X` 快捷命令）：触发面唯一。

## Consequences

- 破坏性变更（交互层面）：习惯在输入框直接敲 `/help` 的用户需改为
  `Esc` → `:`；`/` 开头的 prompt 文本不再需要规避命令解析。README
  键位表、`/help` 输出、欢迎页与 `?` 帮助弹层同步更新。
- `App` 增加 `command: Input` 字段；`Input` 的补全启用从「模式切换时同
  步」简化为「构造时确定」（草稿常驻关闭、命令行常驻开启），模式迁移
  路径上的补全状态同步代码全部移除。
- INSERT 的 Enter 分发从四类（补全/命令/模板/prompt）收敛为两类
  （prompt/排队），运行中亦然；命令分发的运行态裁决集中在
  `dispatch_command` 一处。
- 粘贴（bracketed paste / Ctrl+V）在 COMMAND 下进入命令缓冲，其余模式
  行为不变。
