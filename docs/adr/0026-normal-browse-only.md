# ADR-0026: NORMAL 纯浏览化（移除消息游标与内容操作层）

- 状态：已接受
- 日期：2026-08-15
- 取代：ADR-0021 中 NORMAL 的消息游标、`[`/`]`/`{`/`}` 跳转、`/` 搜索、
  `y` 复制菜单与 `Space` 条目折叠部分

## 背景

ADR-0021 把 NORMAL 定义为「单字母动作层」，其中有一组围绕**消息游标**的
内容操作：进入 NORMAL 时游标定位到最新一条消息，gutter 用 `▐` 整行高亮
当前条目，`[`/`]`/`{`/`}` 在消息/工具条目间移动游标，`Space` 折叠/展开
游标条目，`y` 打开以游标为预选的复制菜单，`/` 搜索以游标为跳转锚点。

实际使用中这组能力带来几个问题：

1. **浏览与选择的职责耦合**：NORMAL 既是「只看不写」的浏览态，又隐式持有
   一个选中条目。用户只是想滚上去看上面的输出，却得到一个会高亮、会滚动
   到位的游标，视觉噪音大于收益；
2. **状态与渲染耦合面大**：消息游标需要「条目起始行」几何（ADR-0025 为
   支持游标滚动定位才把起始行算进状态层）、gutter 高亮重建样式、跨空行
   高亮延续等一整套渲染逻辑；
3. **功能重叠**：`y` 复制菜单与 `Y`/`/copy` 复制最新消息重叠，`Space`
   条目折叠与 `/thinking` 折叠是两个并存的折叠概念，`/` 搜索在终端里
   收益有限（历史内容通常可直接用系统终端搜索/滚轮浏览）。

## 决策

NORMAL 退化为**纯浏览态**，不再持有消息游标，也不再做任何以「选中条目」
为前提的内容操作。NORMAL 只保留 less 式滚动与离开动作：

- 保留：`j`/`k`/`d`/`u`/`g`/`G` 滚动、`Y` 复制最新消息、`m` 队列、
  `r` 重试、`s`/`b`/`c` 会话、`e` 编辑器、`:` 命令、`?` 帮助、
  `q` 中断/退出、`i`/`a`/`A`/`I`/`Enter` 回输入；
- 移除：`[`/`]`/`{`/`}` 消息/工具跳转、`/`/`n`/`N` 搜索、`y` 复制菜单、
  `Space` 条目折叠；
- 移除 SEARCH 与 COPYMENU 两个派生模式（连同 `Search`、`CopyMenu` 状态与
  对应渲染 overlay）；
- 移除 `Chat::cursor_item` 与条目级 `collapsed` 字段；`chat_lines` 不再需要
  游标参数与条目起始行，只返回折行后的逻辑行。

复制需求由 `Y`（NORMAL）与 `/copy`（命令）统一满足——两者都是「复制最新
一条消息」，覆盖绝大多数场景；逐条选择复制在纯浏览语义下不再成立。

## 后果

- 状态层更薄：`Chat` 只保留条目 + 滚动；几何计算（`sync_geometry`）只需
  总行数用于滚动上限，不再维护条目起始行；
- 渲染更薄：gutter 高亮（`▐`/`restyle_highlight`/`highlight_bg`/
  `cursor_marker`）与搜索命中高亮（`search_hit`）全部删除；
- README 键位表、`?` 帮助弹层、欢迎页与状态栏键位提示同步精简；
- 负面：失去「逐条跳转 + 选择复制」能力；若后续需要，应作为独立的选择态
  （如 VISUAL）重新引入，而不是再往浏览态里塞游标。
