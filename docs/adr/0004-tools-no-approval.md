# ADR-0004: 最小工具集，无交互审批

## Status

Accepted

## Context

TUI 优先形态下，工具权限模型可选：交互式审批（危险操作弹窗确认）、
全自动 + 边界限制、沙箱。初期范围需要明确的权限策略。

## Decision

- **工具集最小化**：读文件、写文件、执行 shell 命令、列目录、内容
  搜索（grep/glob）。
- **无交互审批**：工具调用自动执行，不在 TUI 弹确认。
- **边界限制**：所有文件与 shell 操作限定在启动时的工作目录内，
  目录外路径一律拒绝（含符号链接逃逸的 lexical 校验）。
- 沙箱、白名单、审批流程均列为非目标。

## Consequences

- agent 误操作的风险由用户自担，规格与 CLI 帮助中需明确声明。
- 权限校验逻辑集中在工具层一处，后续加审批只需在此挂确认回调。
