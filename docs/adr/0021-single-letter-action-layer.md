# ADR-0021: 单字母动作层交互设计（快捷键重设计）

- 状态：已接受
- 日期：2026-05-13
- 取代：ADR-0011（vim-like 模式化交互）的键位部分；ADR-0018/0019/0020 中
  涉及的键位引用以本 ADR 为准
- 被取代：NORMAL 的消息游标与内容操作（跳转/搜索/复制菜单/条目折叠）由
  ADR-0026（NORMAL 纯浏览化）移除

## 背景

ADR-0011 确立的 vim-like 多模式交互在实际使用中暴露出三类问题：

1. **序列键负担**：`gg`、`[m`、`]t`、`yy`、`dd` 等双键序列依赖 `pending_key`
   状态机，记忆与实现成本高，且与「单键直达」的成熟 TUI 惯例（lazygit、
   k9s、less）相悖；
2. **模式碎片化**：VISUAL 模式只承担「范围选择复制」一个职能，却带来
   完整的模式分支（徽标、光标形状、渲染、键位路由）；
3. **中断语义不符合领域惯例**：同类 agent TUI（Claude Code、opencode）
   以 `Esc` 中断运行，本应用此前用 `Ctrl+C`，肌肉记忆错位。

参考成熟 TUI 的键位范式重新设计：

| 工具 | 借鉴点 |
| ---- | ------ |
| lazygit / k9s | 非输入态单字母直达动作；`?` 帮助；`q` 退出 |
| less | `g`/`G` 顶/底、`d`/`u` 半页、`/` 搜索、`n`/`N` 跳转 |
| weechat / irssi | 输入优先，滚动不抢焦点 |
| Claude Code / opencode | `Esc` 中断运行、`Enter` 发送、`↑` 历史 |
| fzf | picker 输入即过滤、箭头导航 |
| zellij | 状态栏常驻键位提示条 |

## 决策

### 交互骨架：双态 + 叠加层

- **INSERT（输入态，默认）**：打字与提交；readline 编辑键。
- **NORMAL（动作态）**：单字母动作层，输入字符不入缓冲。
- **叠加层**（picker、队列、帮助、复制菜单、搜索条）：覆盖于两态之上，
  各自作用域；非过滤类叠加层同样使用单字母词汇。

### NORMAL 键位（单字母动作层）

| 键 | 动作 |
| -- | ---- |
| `i` `a` `Enter` `A` `I` | 进入 INSERT（光标原位 / 末尾 / 行首） |
| `Esc` | 运行中：中断运行；空闲：回 INSERT |
| `j` `k` | 下/上滚动一行 |
| `d` `u` | 半页下/上（less 惯例） |
| `g` `G` | 顶部 / 底部（less 惯例，取代 `gg`） |
| `[` `]` | 上一条 / 下一条消息（取代 `[m` `]m`） |
| `{` `}` | 上一个 / 下一个工具调用（取代 `[t` `]t`） |
| `/` | 搜索；`n` `N` 下一个/上一个命中 |
| `y` | 复制菜单（overlay 列出消息与代码块，含数字键直达） |
| `Y` | 直接复制最新一条消息 |
| `Space` | 折叠/展开当前条目为单行摘要 |
| `m` | 队列编辑 overlay（取代 `Q`） |
| `m` | 队列编辑 overlay（取代 `Q`） |
| `s` `b` `c` | 会话命令直达：恢复会话 / 会话树（创建分支）/ 新建会话 |
| `r` | 重试最近失败的一轮（等价 `/retry`） |
| `e` | 外部编辑器编辑草稿（等价 INSERT `Ctrl+G`） |
| `:` | 命令输入框（COMMAND，预填 `/`，Tab 补全） |
| `?` | 键位帮助弹层 |
| `q` | 运行中：中断本轮（留在 NORMAL）；空闲：退出 |

废除：`gg`/`[m`/`]m`/`[t`/`]t`/`yy`/`yc` 等全部序列键（`pending_key`
状态机随之移除）、VISUAL 模式（条目级复制菜单取代范围选择）、NORMAL 的
`x`/`dd`/`dw` 草稿编辑（草稿编辑统一回 INSERT，`Ctrl+W/U` 已覆盖高频
删除场景）。

### INSERT 键位

| 键 | 动作 |
| -- | ---- |
| `Enter` | 发送（运行中排入统一消息队列） |
| `Shift+Enter` / `Ctrl+J` | 手动换行（后者为全终端兼容兜底） |
| `↑` `↓` | 输入历史召回（提交过的 prompt，含暂存还原） |
| `Ctrl+A/E` `Ctrl+W` `Ctrl+U` `Alt+B/F` | 行首/尾、删词、清行、词移动（readline 惯例） |
| `Ctrl+V` | 粘贴剪贴板图片 |
| `Ctrl+G` | 外部编辑器编辑草稿 |
| `Esc` | 回 NORMAL（运行中亦然，不中断；中断在 NORMAL 按 `q` 或再按一次 Esc） |
| `Ctrl+C` | 清草稿；草稿已空时退出（运行中同样退出，先中断） |
| `Ctrl+D` | 草稿为空时退出（EOF 惯例）；非空时删除光标处字符 |
| `PgUp` `PgDn` 滚轮 | 滚动聊天区（不切态，weechat 式） |

### 叠加层统一约定

非过滤类叠加层（复制菜单、队列、帮助）：`j`/`k`/`↑`/`↓` 移动、
`g`/`G` 首/尾、`Enter` 确认、`Esc`/`q` 关闭、`?` 帮助。

例外：picker（`/resume`、`/models`、`/tree`）过滤优先——可打印字符即过滤，
导航走 `↑`/`↓` 与 `Ctrl+N/P`（fzf 式），不使用单字母导航。

### 显式避开的键

- `Ctrl+S`/`Ctrl+Q`：终端流控（XON/XOFF）；
- `Ctrl+H`/`Ctrl+I`/`Ctrl+J`/`Ctrl+M`：与 Backspace/Tab/LF/Enter 同码
  （`Ctrl+J` 作换行兜底是刻意的同码利用）；
- `Ctrl+Shift+*`：多数终端不上报；
- `Alt+<字母>` 仅保留 readline 惯例的 `Alt+B/F`。

### 可发现性

- 状态栏常驻键位提示条（zellij 式），随模式/叠加层切换内容；
- `?` 帮助弹层按分组完整列出；
- `:` 命令行带 Tab 补全与摘要，兜住全部低频命令。

## 影响

- `pending_key` 序列键状态机整体移除，NORMAL/QUEUE/HELP 键位路由简化；
- VISUAL 模式（`Mode::Visual`、`Chat::visual_anchor`、徽标与渲染分支）
  整体移除；
- 新增：复制菜单 overlay、输入历史召回、条目级折叠；
- picker 键位不变（过滤优先是本设计明确保留的例外）；
- README「TUI 键位」章节与 `?` 帮助弹层以本 ADR 为准重写。

## 修订

- **2026-05-16：会话快捷键分离**。`s` 会话菜单 overlay（恢复 / 新建 /
  分支树合一入口）拆分为三个直达键：`s` 恢复会话（`/resume`）、`b`
  会话树创建分支（`/tree`）、`c` 新建会话（`/new`），与 COMMAND 下
  会话命令同一「运行中拒绝」口径。`n`/`N` 保留 less 惯例的搜索命中
  跳转，故新建会话不占 `n`（取 `c`，create）。会话菜单 overlay 与
  `PickerKind::Session` 随之移除。
- **2026-08-15：Esc 纯化为层回退，`q` 收敛为带守卫的退出**。两键各自
  独占一个「退出」维度：**Esc 退界面栈**（补全/过滤 → 叠加层 → NORMAL
  → INSERT），纯结构导航，永不中断运行、永不丢数据，恢复全局
  mash-safe 不变量；**`q` 退活动栈**（运行中的轮次 → 程序），是唯一
  携带破坏性的键。具体变更：
  - NORMAL 运行中 `Esc` 不再中断运行（改为回 INSERT）；中断由 `q`
    的确认态第一阶段承担。这部分回退了本 ADR 的「Esc 中断对齐
    Claude Code/opencode 惯例」决策：Esc 语义分裂（有时回退、有时
    中断）要求按键前判断运行状态，代价大于跨工具惯例的收益；
  - `q` 新增二次确认守卫：运行中第一次按中断本轮并进入确认态
    （notice 提示「再按 q 退出」，2s 超时 / 按其他键 / 运行结束解除），
    确认态中第二次按退出；空闲但有未发送草稿、附件或排队消息时
    同样需确认；干净空闲直接退出（session 已落库，零损失）。与
    INSERT `Ctrl+C`「清草稿→再按退出」的守卫同构；
  - 确认态期间冻结 `drain_queue`，防止中断后队列自动续跑抢占确认
    窗口；
  - HELP 弹层不再响应 `q` 关闭（层导航归 Esc 专属）；`Ctrl+C`
    维持各模式硬退出不变，作为专家用户绕过确认的快路径。
