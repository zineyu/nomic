# ADR-0002: 交互式 TUI 作为初期主要形态

## Status

Accepted

## Context

「coding agent 初期脚手架」的运行形态可选：库优先（嵌入他人应用）、
headless CLI（脚本化、单 prompt 进出）、交互式 TUI。

## Decision

**交互式 TUI 优先**。agent 的主要使用方式是用户在终端里打开 nomic、
多轮对话地驱动它完成编码任务。库核与 CLI 形态不作为初期交付目标；
但如果 TUI 与核心 loop 之间的边界自然形成，不刻意阻止核心逻辑沉淀为
可复用模块。

## Consequences

- 初期范围必须包含：流式输出渲染、对话历史展示、用户输入编辑与提交、
  中断/退出等完整交互闭环。
- 交互式审批（危险操作确认）成为可能，纳入后续决策范围。
- 不考虑无终端环境的嵌入场景，UI 与核心的边界可以适度宽松。
- TUI 框架选型（ratatui 等）由我查证后给方案。
